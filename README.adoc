= Relaton Open Project Site

== Introduction

This is the Relaton project site,
part of Ribose Open Project network,
located at https://www.relaton.com.

It is a https://jekyllrb.com[Jekyll]-based site
created with the Open Project Jekyll theme.

Refer to their respective docs for details.


== Content management

=== Adding new bibliography type

Supported bibliography types are configured in the main `_config.yml`
under `relaton.supported_bibliographies`,
and adding a new type is as easy as inserting an item into that YAML array.

Array item format is described below:

[source,yaml]
----
relaton:
  supported_bibliographies:
  - id: iso
    # This must be CSS class name compliant, no spaces or non-ASCII characters

    label: ISO
    # Human-readable label, usually organization or standard type

    gem: relaton-iso
    # Name of the corresponding Ruby gem, exactly as listed under `_software/{gem name}.adoc`

    sources:
      - { url: "https://iso.org/", label: "ISO.org website" }
    # List of sources used by the gem for fetching bibliographies.
    # `url` and `label` are optional, but at least one of those must be present for each source
----


== Development

=== Workers static-assets deployment (relaton.org#112)

The Astro `dist/` output deploys as a Workers static-assets site
(`wrangler.jsonc`, no `main` script — assets-only worker `relaton-www`):

* Current surface: `https://relaton-www.relaton.workers.dev` (deployed;
  `.github/workflows/deploy_workers.yml` rebuilds and deploys on push to
  `main`, using the `CLOUDFLARE_API_TOKEN` / `CLOUDFLARE_ACCOUNT_ID`
  repo secrets)
* Cutover pending (owner decision, relaton-api-js#175 D3): www.relaton.org
  is currently GitHub Pages proxied through Cloudflare. Moving the
  hostname to the worker means releasing the Pages CNAME and attaching
  the custom domain route — do not flip while Pages is the canonical
  surface. GitHub Pages `build_deploy.yml` stays as the fallback until
  then.

**Search for Agents** (zone AI Search, beta 2026-11-25): enable via the
one-toggle dashboard switch on the relaton.org zone (owner-side). It
gives agents a hosted full-text search endpoint over the site; it is
deliberately complementary to our own https://mcp.relaton.org[mcp.relaton.org]
server — hosted search = full-text findability, our MCP = structured
graph + canonical keys + pubid identifier resolution. Verify the toggle
by querying the hosted endpoint against our content, and confirm
`sitemap-index.xml` (+ `llms.txt` when #111 lands) is picked up by the
index.

=== Getting started

* Ensure you have reasonable Ruby version
* Run `bundle` from within site directory to install Ruby dependencies

=== Serving site preview

* Run `jekyll serve` from within site directory
